# kumi

[Русский](https://github.com/Tensorcery/kumi/blob/main/docs/langs/ru/README.md)

A tool that assembles projects from versioned blocks.

A block is a self-contained set: a Copier template, files, AI skills,
anything. Everyone writes their own blocks; they live in a hub repository
together with the list of projects built from them. kumi is a layer over
Copier and other templaters, not a replacement for them.

Early stage: only `kumi --version` exists so far.
