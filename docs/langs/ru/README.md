# kumi

[English](../../../README.md)

Инструмент, который собирает проекты из версионированных блоков.

Блок - цельный набор: шаблон Copier, файлы, скиллы для ИИ, что угодно.
Блоки каждый пишет свои; они живут в хаб-репозитории вместе с перечнем
проектов, которые из них собраны. kumi - надстройка над Copier и другими
шаблонизаторами, а не замена им.

Ранняя стадия: пока есть только `kumi --version`.
